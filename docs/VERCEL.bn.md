## ১. আপনার কাছ থেকে যা লাগবে — শুধু একটিই জিনিস

**Vercel API Token।** এর বাইরে আর কিছু লাগে না — না পাসওয়ার্ড, না GitHub, না Supabase-এর নতুন কিছু (publishable key আমার কাছে আছে)।

### টোকেন বানানোর নিয়ম

1. [vercel.com/account/tokens](https://vercel.com/account/tokens) → **Create Token**
2. **Token Name:** `rangpur-ssc96` · **Scope:** Personal Account (বা আপনার Team, যদি Team-এ হোস্ট করতে চান) · **Expiration:** 1 Day (ডিপ্লয় শেষ হলে আর লাগবে না)
3. **Create** → টোকেন একবার দেখাবে — কপি করে চ্যাটে পাঠান

⚠️ এটি গোপন কী। আমি:

- `/home/user/.vercel-token` ফাইলে **mode 600**-এ রাখব
- কখনো আউটপুটে/লগে ছাপব না
- ZIP বা প্রজেক্ট ফাইলে রাখব না
- **ডিপ্লয় শেষ হলে আপনি চাইলে সঙ্গে সঙ্গে Revoke করে দিতে পারেন** (Vercel → Tokens → … → Delete)

## ৪. Serverless-এ যা যা খেয়াল রাখা হয়েছে

- **অ্যাডমিন সেশন:** কুকি-ভিত্তিক, প্রতিটি ফাংশনেই কাজ করে (মেমোরিতে কিছু জমা রাখা হয় না)।
- **ডেমো মোড:** Vercel-এ ডেমো বন্ধ (ফাইল লেখা যায় না) — শুধু আসল ডেটাবেস চলে।
- **স্প্যাম-নিয়ন্ত্রণ:** রেট-লিমিট প্রতি ইনস্ট্যান্সে; প্রয়োজন হলে Vercel-এর Firewall দিয়ে বাড়ানো যাবে।
- **কোল্ড স্টার্ট:** প্রথম অনুরোধে ১–২ সেকেন্ড বেশি লাগতে পারে, পরে স্বাভাবিক।
- **পাসওয়ার্ড রিসেট ইমেইল:** Supabase Auth-এর ফ্রি টিয়ারে **ঘণ্টায় সীমিত** ইমেইল পাঠানো যায়; বেশি লাগলে Supabase-এর SMTP (Resend/Brevo) যোগ করবেন — `docs/SUPABASE_ACCESS.bn.md` দেখুন।

## ৫. নিজে হাতে ডিপ্লয় করতে চাইলে (৬ ধাপ)

```bash
# ১) প্রজেক্ট ফোল্ডারে ঢুকুন
cd rangpur-ssc96

# ২) Vercel CLI
npm i -g vercel

# ৩) লগইন (ব্রাউজারে অনুমতি দেবে)
vercel login

# ৪) প্রথম ডিপ্লয় (প্রশ্নের উত্তর: Link to existing? No · Framework: Vite)
vercel

vercel env add DATA_MODE production        # ইত্যাদি…

vercel --prod
```

সফল হলে Vercel একটি লিংক দেবে, যেমন `https://rangpur-ssc96.vercel.app` — সেটাই আপনার সবার জন্য খোলা ঠিকানা।

## ৬. Custom Domain (ঐচ্ছিক)

Vercel → Project → **Settings → Domains → Add** → যেমন `rangpurssc96.com`। তারপর ডোমেইন-রেজিস্ট্রারে Vercel যা দেখাবে সেটি বসাতে হবে:

| প্রকার | নাম   | মান                    |
| ------ | ----- | ---------------------- |

| CNAME  | `www` | `cname.vercel-dns.com` |

DNS ছড়াতে ৫ মিনিট – ৪৮ ঘণ্টা লাগতে পারে। সাবডোমেইন যেমন `app.rangpurssc96.com` হলে শুধু CNAME লাগে।

## ৬.১ ইমেইল (রিসেট-লিংক) ঠিক করা হয়েছে

**আগে কাজ করছিল না কেন — তিনটি কারণ ছিল:**

| কারণ                                                                             | অবস্থা এখন                                                                                         |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| সাইটের URL ছিল `localhost:3000` — রিসেট-লিংক তাই আপনার ফোনে খুলত না              | ✅ `localhost` + `*.vercel.app/admin/reset` অনুমোদিত; Vercel URL পাওয়ার পর চূড়ান্ত করে দেব       |
| অ্যাপে পাসওয়ার্ড ভুলে যাওয়ার **কোনো বাটনই ছিল না**                             | ✅ এখন লগইন পেজে "পাসওয়ার্ড ভুলে গেছেন?" বাটন ও নতুন পাসওয়ার্ড বসানোর পর্দা আছে (`/admin/reset`) |
| Supabase-এর ডিফল্ট ইমেইল-সেবা ব্যবহার হচ্ছিল (ঘণ্টায় ২টি, তাও প্রায়ই স্প্যামে) | ⚠️ এখনো ডিফল্ট — নিজের SMTP বসালে নির্ভরযোগ্য হবে (নিচে দেখুন)                               |

**যা যাচাই করা হয়েছে (আসল ইমেইলে, ইমেইল না পাঠিয়েই):**
রিসেট-লিংক তৈরি → লিংক খুললে টোকেন → নতুন পাসওয়ার্ড বসানো → নতুন পাসওয়ার্ডে লগইন **সফল** → আবার আগের পাসওয়ার্ড ফিরিয়ে দেওয়া **সফল** (`admin.password_resets`-এ `completed` লেখা হয়েছে)।

### এখনও ইমেইল না এলে যা করবেন

1. **স্প্যাম / প্রমোশনস** ফোল্ডার দেখুন (Supabase-এর ডিফল্ট প্রেরক সেখানে পড়ে)।
2. ঘণ্টায় **২টির বেশি** রিসেট চাইলে ব্লক হয় — কিছুক্ষণ অপেক্ষা করুন।
3. **পরে পাবলিক হোস্ট করলে নিজের SMTP বসানোই ভালো** (Resend/Brevo-র ফ্রি টিয়ার বেশি নির্ভরযোগ্য):
   Supabase → Project Settings → **Authentication → SMTP Settings** → Host/Port/User/Password → Save।
   তারপর `admin.email_outbox` কেবল হিসাব রাখবে, আসল পাঠানো হবে আপনার SMTP থেকে।
4. ভুলে গেলে চিরস্থায়ী বিকল্প (SMTP ছাড়াও কাজ করে): Supabase → **Authentication → Users → আপনার অ্যাকাউন্ট → Reset/Update password**।

### ইমেইল প্রসঙ্গে জরুরি কথা
Supabase-এর **ডিফল্ট ইমেইল সেবা ঘণ্টায় মাত্র ২টি** পাঠায় — API দিয়ে এর সীমা বাড়ানো যায় না (কাস্টম SMTP বসালে তবে যায়)। তাই **নিজের SMTP বসানোই আসল সমাধান**:
1. [resend.com](https://resend.com) (বা Brevo) → ফ্রি অ্যাকাউন্ট → API Key
2. Supabase → Project Settings → **Authentication → SMTP Settings**: Host `smtp.resend.com` · Port `465` · User `resend` · Password = আপনার API key · Sender email = আপনার যাচাই করা ঠিকানা
3. Save → তারপর ঘণ্টায় ৩০+ (ব্রেক-এর ফ্রি টিয়ারে দিনে ৩০০) পাঠানো যাবে

API key-টা চ্যাটে দিলে আমি বসিয়ে যাচাই করে দেখে দেব।
