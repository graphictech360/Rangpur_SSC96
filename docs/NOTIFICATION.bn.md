## ধাপ ১ — Resend-এ ফ্রি অ্যাকাউন্ট (২ মিনিট)

1. ব্রাউজারে যান: **https://resend.com/signup**
2. **graphictech360@gmail.com** দিয়ে সাইন-আপ করুন (এটাই ভালো — নিচের কারণে)।
3. ইমেইলে আসা লিংকে চাপ দিয়ে অ্যাকাউন্ট চালু করুন।
4. চালু হয়ে গেলে ডান-উপরে **API Keys** → **Create API Key**
   - Name: `rangpur-ssc96`
   - Permission: **Sending access** (এটুকুই যথেষ্ট)
5. যে চাবিটি দেখাবে (`re_` দিয়ে শুরু, একবারই দেখা যায়) — কপি করে রাখুন।

> **কেন আপনার Gmail-এ সাইন-আপ করবেন?** Resend-এর ফ্রি প্ল্যানে
> `onboarding@resend.dev` থেকে **শুধু নিজের অ্যাকাউন্টের ইমেইলেই** পাঠানো যায়।
> আমরা ঠিক সেটাই করছি (খবর যাচ্ছে graphictech360@gmail.com-এ) — তাই
> **কোনো ডোমেইন কেনা বা যাচাই করার দরকার নেই**, আজই চালু হবে।
> পরে চাইলে নিজের ডোমেইন যোগ করে যেকোনো ঠিকানায় পাঠাতে পারবেন।

## ধাপ ২ — চাবিটা Vercel-এ বসানো

Vercel → **rangpur-ssc96** প্রকল্প → **Settings** → **Environment Variables** →
নিচের ৪টি যোগ করুন (Environment: **Production**), তারপর **Redeploy**:

| Name | Value |
| ---- | ----- |
| `RESEND_API_KEY` | ধাপ ১-এ পাওয়া `re_…` চাবি |
| `NOTIFY_EMAIL` | `graphictech360@gmail.com` |
| `QUICK_LOGIN_EMAIL` | `graphictech360@gmail.com` |
| `QUICK_LOGIN_PASSWORD` | আপনার অ্যাডমিন প্যানেলের পাসওয়ার্ড (যেটা দিয়ে লগইন করেন) |

> `NOTIFY_FROM` না দিলে `Rangpur SSC 96 <onboarding@resend.dev>` থেকে মেইল যাবে — এটাই ঠিক আছে।
> **উপনাম:** চাইলে আপনার চাবিটি আমাকে দিলে আমি নিজেই বসিয়ে দেব ও পরীক্ষা করে দেখাব
> (চাবি কোথাও লিখে রাখব না, প্রজেক্ট ফাইলে ঢুকব না)।

একবার ফোন বা কম্পিউটার থেকে সাইটে ঢুকে একটি নকল নিবন্ধন করে দেখুন:

1. https://rangpur-ssc96.vercel.app → **নিবন্ধন** → ফর্ম পূরণ (ছবি দিয়ে) →
   পেমেন্ট তথ্য লেখার সময় আপনার নিজের নম্বর থেকে সত্যি টাকা পাঠাবেন না —

2. কয়েক সেকেন্ডের মধ্যে Gmail চেক করুন — মেইল এসেছে কি না।
3. মেইলের সবুজ ব্যানারের নিচে **এক ক্লিকে প্যানেলে যাই** বোতামে চাপ দিন —
   প্যানেল খুলে যাবে।

## নিরাপত্তা

- চাবি শুধু Vercel-এর Environment Variables-এ থাকবে; কোড/গিটহাবে কিছু যায় না
- এক-ক্লিক লিংকে সই-করা টোকেন থাকে, **৬০ মিনিট পরে নিজে থেকেই অচল**;
  কেউ টোকেন বদলে দিলে সার্ভার সাথে সাথে ফিরিয়ে দেয় (পরীক্ষা করা আছে)
- মেইলে **নিবন্ধনকারীর গোপন টিকিট-লিংক থাকে না** — শুধু প্যানেলে ঢোকার নিজের লিংক
- খবর পাঠাতে কোনো কারণে সমস্যা হলেও **নিবন্ধন কখনো আটকাবে না** — সবসময় জমা হবে

## খবর বন্ধ করতে চাইলে

Vercel থেকে `RESEND_API_KEY` মুছে দিন (বা `NOTIFY_EMAIL` খালি করুন) → আর মেইল যাবে না,
নিবন্ধন আগের মতোই চলবে।

## বিকল্প: ডোমেইন ছাড়া অন্য উপায় (ওয়েবহুক)

Resend ব্যবহার করতে না চাইলে Google Apps Script দিয়ে Gmail-এর নিজের
`MailApp.sendEmail()` দিয়েও চলবে — সেক্ষেত্রে শুধু `NOTIFY_WEBHOOK_URL`
(Apps Script Web App-এর ঠিকানা) বসাতে হবে; মেইলের হুবহু একই HTML সেটিতে পাঠানো হয়।
বিস্তারিত জানতে চাইলে বলুন, ধাপে ধাপে দেখিয়ে দেব।
