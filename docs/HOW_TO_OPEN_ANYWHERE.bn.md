# অন্য মোবাইল/কম্পিউটারে খোলার তিনটি উপায় (লিংকসহ)

প্রশ্ন: **“অন্য ফোনে বা কম্পিউটারে খোলার কোনো লিংক আছে?”**

উত্তর সোজা: **এই মুহূর্তে কোনো পাবলিক লিংক নেই।** কারণ এই অ্যাপ এখনো কোথাও হোস্ট করা হয়নি—এটি আপনার কম্পিউটারে/স্যান্ডবক্সে চলে। নিচের তিনটি পথের যেকোনো একটি নিলেই আপনি “লিংক” পেয়ে যাবেন।

| উপায়                        | লিংক হবে?                        | কারা খুলতে পারবে                 | কী লাগবে                                 |
| ---------------------------- | -------------------------------- | -------------------------------- | ---------------------------------------- |
| **১. অফলাইন ফাইল**           | লিংক নেই, ফাইলটি শেয়ার করতে হয় | যাকে ফাইল পাঠাবেন                | কিছুই না (সবচেয়ে সহজ)                   |
| **২. একই Wi-Fi-এর লিংক**     | `http://192.168.x.x:3000`        | একই Wi-Fi-তে থাকা সবাই           | আপনার কম্পিউটারে Node.js                 |
| **৩. পাবলিক লিংক (হোস্টিং)** | `https://your-name.onrender.com` | সারা দুনিয়ার যেকোনো ফোন/ল্যাপটপ | Supabase অ্যাকাউন্ট + হোস্টিং অ্যাকাউন্ট |

## ১. অফলাইন ফাইল — কোনো লিংক লাগে না

ফাইল: **`Rangpur-SSC96-Preview.html`** (≈৩.৫ MB)

- ইমেইল/Google Drive/পেনড্রাইভ দিয়েও চলে।

⚠️ এতে নিবন্ধন শুধু ওই ডিভাইসের ব্রাউজারে থাকে—অন্য কেউ সেটা দেখতে পাবে না।

## ২. একই Wi-Fi-এর লিংক (আপনার কম্পিউটারেই সার্ভার)

১. নিজের কম্পিউটারে [Node.js 20+](https://nodejs.org) ইনস্টল করুন।
২. প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে:

```bash
npm ci
npm run share
```

৩. স্ক্রিনে এমন লিংক দেখাবে:

```
═════════════ অন্য ডিভাইসে খোলার লিংক ═════════════
একই Wi-Fi-তে থাকা যেকোনো ফোন/ল্যাপটপের ব্রাউজারে খুলুন:
   http://192.168.0.105:3000
```

৪. পরিবারের/বন্ধুর ফোন—একই Wi-Fi-তে থেকে এই লিংকটি খুলুন। অ্যাডমিনও একই লিংকে `/admin` পথে।

**কাজ না করলে:**

- **Windows:** প্রথমবার চলার সময় “Windows Defender Firewall — Allow access” বার্তায় **Private networks** টিক দিন।
- **macOS:** System Settings → Network → Firewall → Node-কে allow করুন।
- মোবাইল হটস্পট দিয়ে কম্পিউটারকে যুক্ত করলে: হটস্পট দেওয়া ফোনেই `npm run share` চালালে সবচেয়ে ভালো; স্ক্রিনে দেখানো `http://172.20.x.x:3000` লিংকটিই ব্যবহার করুন।
- স্কুল/অফিসের Wi-Fi-তে ডিভাইসগুলো আলাদা করে রাখলে লিংক নাও খুলতে পারে; সেক্ষেত্রে মোবাইল হটস্পট ব্যবহার করুন।

⚠️ কম্পিউটার বন্ধ বা টার্মিনাল বন্ধ হলে লিংক বন্ধ। QR স্ক্যান করতে মোবাইলে ক্যামেরার অনুমতি দিন (এখানে HTTP হলেও Chrome সাধারণত অনুমতি দেয়; না দিলে ছবি আপলোড করে চেক-ইন করা যায়)।

## ৩. পাবলিক লিংক — সবার জন্য স্থায়ী (Supabase + Render)

এর জন্য দুইটি ফ্রি অ্যাকাউন্ট দরকার। পুরো কাজ ~২০ মিনিট।

### ধাপ ক) Supabase-এ ডেটাবেস তৈরি

1. [supabase.com](https://supabase.com)-এ লগইন করে প্রকল্প **`Rangpur_SSC96`** (URL: `https://mbuzwqsrnmergrtetwqq.supabase.co`) খুলুন।
2. **SQL Editor** → **New query** → `supabase/01_schema.sql`-এর পুরো লেখা পেস্ট করে **Run**।
3. একইভাবে `supabase/02_seed.sql` চালান (১৩টি কনটেন্ট, ১৪টি সময়সূচি, ৮টি বিকাশ/নগদ নম্বর বসবে)।
4. **Authentication → Users → Add user** → নিজের ইমেইল+পাসওয়ার্ড দিয়ে আপনার অ্যাকাউন্ট বানান (Email confirm করাতে হবে)।
5. **SQL Editor**-এ `supabase/03_staff_setup.sql` চালান—আপনার অ্যাকাউন্ট তখন **owner/admin** হবে।
6. **Project Settings → API** থেকে **Project URL** ও **publishable (anon) key** কপি করুন। _Service-role/secret key কখনো ব্যবহার করবেন না—অ্যাপ সেটি গ্রহণ করে না।_

### ধাপ খ) কোড হোস্টিং-এ তোলা (Render-এর উদাহরণ)

1. কোডটি GitHub-এ একটি (private হলে ভালো) রিপোজিটরিতে পুশ করুন—`Rangpur-SSC96-App.zip` খুলে পাওয়া ফোল্ডারটিই যথেষ্ট।
2. [render.com](https://render.com) → **New → Web Service** → রিপোজিটরি বেছে নিন।
3. সেটিংস:
   - **Environment:** Node
   - **Build Command:** `npm ci && npm run build`
   - **Start Command:** `npm start`
4. **Environment Variables** যোগ করুন:

   ```env
   NODE_ENV=production
   DATA_MODE=supabase
   SUPABASE_URL=https://mbuzwqsrnmergrtetwqq.supabase.co
   SUPABASE_PUBLISHABLE_KEY=<আপনার publishable/anon key>
   SESSION_SECRET=<নিচের কমান্ডে তৈরি ৩২+ অক্ষরের গোপন কী>
   COOKIE_SECURE=true
   APP_ORIGIN=https://<আপনার-app-নাম>.onrender.com
   TRUST_PROXY=1
   ```

   গোপন কী তৈরির কমান্ড:

   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

5. **Deploy** চাপুন। কয়েক মিনিট পরে লিংক পাবেন: `https://<আপনার-app-নাম>.onrender.com`
6. সেই লিংকটিই এখন **সবাইকে শেয়ার করুন** — যেকোনো ফোন/ল্যাপটপ/ট্যাবে খুলবে, HTTPS থাকায় ক্যামেরা QR স্ক্যানও কাজ করবে।

### ধাপ গ) চালু করার পর যা করবেন

- `/admin` পথে নিজের Supabase ইমেইল/পাসওয়ার্ড দিয়ে লগইন (ডেমো পাসওয়ার্ড এখানে কাজ করবে না)।
- প্রতিটি গেট স্টাফের জন্য আলাদা অ্যাকাউন্ট বানিয়ে `03_staff_setup.sql`-এ ভূমিকা (`scanner`) দিন; তারপর অ্যাডমিন প্যানেল থেকে তার ব্রাউজার/ডিভাইস অনুমোদন করুন।
- নিজের `APP_ORIGIN` ভুল হলে লগইন আটকে যাবে (403) — হোস্টিং-এর চূড়ান্ত domain বসিয়েই deploy করুন।

**জেনে রাখুন:** Render-এর ফ্রি প্ল্যানে কিছুক্ষণ কেউ না খুললে সার্ভার ঘুমিয়ে পড়ে—প্রথম লোডে ৩০–৬০ সেকেন্ড লাগতে পারে। এছাড়া সেশন সার্ভারের মেমোরিতে থাকে, তাই একটি ইনস্ট্যান্সেই চালান; multi-instance চাইলে shared session store দরকার হবে।
