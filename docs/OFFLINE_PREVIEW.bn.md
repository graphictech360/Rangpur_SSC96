# সার্ভার ছাড়া অ্যাপ দেখানো ও শেয়ার করা

এই অ্যাপটি দুইভাবে চলতে পারে:

| ধরন                       | কোথায় চলে                                    | কী কাজ করে                                                                                                                           |
| ------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **অফলাইন প্রিভিউ**        | একটি ফাইল: `Rangpur-SSC96-Preview.html`       | পুরো ডিজাইন, ছবি-অ্যানিমেশন, ফর্ম, ফি হিসাব, অনুমোদন, QR টিকিট, চেক-ইন — সব ব্রাউজারের ভেতরেই। ডেটা শুধু ওই ডিভাইসের ব্রাউজারে থাকে। |
| **আসল অ্যাপ (সার্ভারসহ)** | `npm run dev` চালিয়ে, পরে Supabase+হোস্টিং-এ | সবাই একই লিস্টে নিবন্ধন করেন, আয়োজক সবাইকে এক জায়গায় দেখেন।                                                                        |

## ফাইলটি তৈরি করা (একবার)

```bash
npm ci
npm run preview:build      # বানায়: ../Rangpur-SSC96-Preview.html
```

ফাইলটি তৈরি হয় প্রজেক্টের ঠিক বাইরে, অর্থাৎ `/home/user/Rangpur-SSC96-Preview.html`। CSS, JavaScript, বাংলা ফন্ট (Noto Sans Bengali, Outfit, DM Serif) ও আপনার দেওয়া সব ছবি ফাইলের ভেতরেই বসানো থাকে—তাই ইন্টারনেট লাগে না।

## অন্য মোবাইল / ল্যাপটপে দেখানোর সহজ উপায়

### ১. হোয়াটসঅ্যাপ / টেলিগ্রাম / মেসেঞ্জার

- `Rangpur-SSC96-Preview.html` ফাইলটি নিজের "নিজের নম্বরে" (Saved messages) বা বন্ধুর চ্যাটে **ডকুমেন্ট হিসেবে** পাঠান।
- ফোনে ফাইলটিতে ট্যাপ → "Open with Chrome / Safari" → অ্যাপ চালু।
- ⚠️ WhatsApp-এর ভেতরের ব্রাউজারে (`wa.me` preview) নয়—ফাইল ডাউনলোড করে **আসল Chrome/Safari-তে** খুললে সবচেয়ে ভালো চলে।

### ২. ইমেইল

নিজের Gmail-এ ফাইলটি অ্যাটাচ করে পাঠান। ফোন/ল্যাপটপ থেকে অ্যাটাচমেন্ট ডাউনলোড করে ট্যাপ/ডাবল-ক্লিক করলেই চলবে।

### ৩. পেনড্রাইভ / মেমোরি কার্ড

ফাইলটি কপি করে যেকোনো কম্পিউটারে ডাবল-ক্লিক করুন। ইন্টারনেট একদম লাগে না।

### ৪. Google Drive / Dropbox

ড্রাইভে ফাইলটি আপলোড → "Share → Anyone with the link" → বন্ধুরা লিংক খুলে **Download** করবে → তারপর ফাইলটি খুলবে। (ড্রাইভের নিজের প্রিভিউতে বাংলা ফন্ট ঠিকভাবে নাও আসতে পারে; ডাউনলোড করে খুললে নিখুঁত দেখাবে।)

### ৫. USB/ব্লুটুথ

পুরোনো ফোনেও ব্লুটুথ দিয়ে পাঠানো যায়; ফাইলটির আকার মাত্র ~৩.৪ MB।

## প্রিভিউয়ের ভেতরে যা করবেন

1. **ডেমো রিসেট** বাটন (নিচে বাঁদিকে)—ডেমো ডেটা মুছে আবার নতুন করে শুরু করে।
2. **“ডেমো তথ্য”**—ফর্ম নিজে থেকেই কাল্পনিক তথ্যে ভরে দেয়।
3. **“কাল্পনিক পেমেন্ট তথ্য বসাও”**—পেমেন্ট ধাপ ভরে দেয়। **বাস্তব টাকা পাঠাবেন না।**
4. **আয়োজক প্যানেল → “ডেমো অ্যাডমিন হিসেবে দেখো”**—অনুমোদন দিলে QR টিকিট তৈরি হয়।
5. ব্যানারে নিজে থেকেই দুইটি ছবি বদলায় (কোলাজ মোশন); নিচের ডটে চাপ দিয়ে যেকোনো ছবিতে যাওয়া যায়।

## যা অফলাইনে হয় না (জেনে রাখুন)

- অফলাইন প্রিভিউতে নিবন্ধন **শুধু ওই ডিভাইসে** থাকে; অন্য ফোনে সেটা দেখা যাবে না।
- আদম টাকা পাঠানো, Supabase Auth, বাস্তব QR স্ক্যান (ক্যামেরা) এসব চালাতে **হোস্ট করা ভার্সন** লাগবে—`README.bn.md`-এর Supabase অংশ দেখুন।
- কিছু ব্রাউজারে (বিশেষ করে iOS Safari-তে সরাসরি ফাইল খুললে) ডেটা রাখার সীমা থাকে; সেক্ষেত্রে ডেমো রিসেট করলেই আবার চলবে।

## ফাইল বদলালে আবার বিল্ড করতে হবে

CSS/ছবি/লেখা বদলালে শুধু:

```bash
npm run preview:build     # নতুন ফাইল
npm run preview:test      # হেডলেস ব্রাউজারে ফর্ম→অনুমোদন→QR যাচাই
```

পুরো প্রজেক্টের সব পরীক্ষা এক ধাপে: `bash scripts/offline-checks.sh`
